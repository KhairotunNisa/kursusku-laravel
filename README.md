
# KursusKu Laravel

## Deskripsi
KursusKu adalah website informasi kursus pemrograman yang dibuat menggunakan framework Laravel.

## Fitur
- Menampilkan halaman utama KursusKu.
- Menampilkan daftar kursus unggulan.
- Menggunakan Route, Controller, dan Blade View.
- Menggunakan CSS untuk desain halaman.

## Teknologi
- PHP
- Laravel
- HTML
- CSS

## Cara Menjalankan Project
1. Buka terminal pada folder project.
2. Jalankan `php artisan serve`.
3. Buka browser dan akses http://127.0.0.1:8000.
