# AI Usage Log — KursusKu Laravel

## 1. Tujuan Penggunaan AI
ChatGPT digunakan sebagai alat bantu untuk memahami materi Laravel, memperbaiki kode, dan menyelesaikan tugas praktikum Pertemuan 7.

## 2. Bentuk Bantuan AI
- Membantu memahami konsep Route, Controller, dan Blade View.
- Memberikan panduan menyusun halaman utama KursusKu.
- Membantu memeriksa kode pada file `home.blade.php`.
- Membantu mengatasi masalah penampilan gambar hero.
- Memberikan panduan menggunakan Git dan membuat commit.
- Membantu menyiapkan bukti pengujian dan dokumentasi project.

## 3. Verifikasi Hasil
Kode dan hasil project diperiksa secara mandiri melalui browser dan terminal. Pengujian route dilakukan menggunakan perintah `php artisan route:list`, sedangkan riwayat perubahan diperiksa menggunakan `git log --oneline`.

## 4. Catatan
AI digunakan sebagai alat bantu pembelajaran. Pemahaman terhadap kode dan hasil akhirnya tetap perlu diperiksa oleh mahasiswa sebelum tugas dikumpulkan.
